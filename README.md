# organization-gists

A collection of small, reusable public snippets for documenting an organization's
identity and claims. Use these files as starting points for information you want
to publish or share, such as Keybase verification references, validation claims,
and public keys.

## Snippets

- [Keybase verification](snippets/keybase-verification.md) — a record that points
  to a Keybase profile and its public proof.
- [Validation claim](snippets/validation-claim.md) — a concise, reviewable record
  of a claim and the evidence supporting it.
- [Public key](snippets/public-key.md) — metadata and a place to publish a
  cryptographic public key.

## Using and contributing snippets

Copy a snippet and replace every bracketed value with accurate information.
Remove fields that do not apply. Keep the content self-contained, link to
authoritative evidence where possible, and include when a claim or key was
checked so readers can judge whether it is current.

These are documentation templates, not proof of identity or automated
verification. Verify any linked proof, claim, fingerprint, and key through its
authoritative source before relying on it. Publish only information intended to
be public: **never include passwords, tokens, private keys, recovery codes, or
other secrets.** Submit changes only after confirming the organization is
authorized to publish the information.
